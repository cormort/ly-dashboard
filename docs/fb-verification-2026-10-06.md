## 查核方法（可重現）

1. `py`／`curl` 直接抓不可行：Facebook 對非瀏覽器請求回 HTTP 400（連續請求後更明顯），
   而且未登入時多數粉專只回泛用標題 `Facebook`。
2. 未登入的純 HTTP 抓取可以做**粗略**比對（有效代稱會回傳頁面標題＝人名，失效代稱只回 `Facebook`），
   這次用它先掃過 113 筆，作為第一層篩選；但**不能**當成結論——吳思瑤的 `taipeineedyou`
   未登入時就是泛用標題，登入後才看得到（頁面有效、最新貼文 2026-10-05）。
3. 真正的判定用**已登入的瀏覽器**（`scripts/fetch-fb-posts.mjs --verify`）：讀 `document.title`、
   頁面追蹤者數、最新貼文日期與內容，再用維基百科條目的 `{{facebook|代稱}}` 模板、
   Wikidata P2013、Facebook 站內搜尋交叉比對。
4. 粉專**代稱（slug）可由管理者隨時更改**，數值 ID 不變；有些來源仍記舊代稱，點進去會自動導向，
   這種不算錯誤。
