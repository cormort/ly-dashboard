## 2. 診斷：四個具體原因

1. **預設頁把所有東西都攤開，卻沒有主角。**
   總覽 33 個 panel、28 個 h3（其中 25 個是各縣市卡片），每張卡都是同樣大小、同樣的「看更多」。
   使用者第一眼看到的是「一堆平行區塊」，而不是「現在最重要的一件事」。
2. **導覽一列 9 個等重項目** → 沒有主題感，視線沒有落點。
3. **字級發散**：11 / 11.67 / 12 / 12.5 / 13 / 14 / 15 / 16 / 17 / 18 / 19 / 22 / 23 / 24 / 27px 混用，
   其中 13px 是最大宗（法案頁 337 個元素都是 13px）→ 因為幾乎所有文字一樣大，就沒有主次。
4. **「次要」用得太氾濫**：每頁 36–51 個 `.muted`、基金頁 54 個標籤 →
   全部都是灰字、全部都是標籤，等於全部都不是重點。

## 3. 做了什麼

### 3.1 導覽改成兩層（最有感的一項）
- 上層收斂成 **5 個主題**：總覽｜委員｜議事｜機關／基金｜最近動態。
- 進入主題後，header 下方出現該主題的**次級導覽**（委員→查詢／比較／排行榜；議事→法案／預算／委員會；
  機關／基金→基金／機關／財團法人／行政法人／主計總處）。
- 網址完全沒變，既有連結與我的分享網址都不會壞。

### 3.2 總覽重新分層
- **一張焦點卡**（最新動態）橫跨兩欄、字大一級、邊框用 accent 色 → 明確的主角。
- 其餘卡片固定兩欄、每張只留 3 則（原本 5 則）。
- **各縣市最新動態改成預設收合的 `<details>`，而且收合時完全不渲染**（25 張卡片的 DOM 不進首次繪製）。
- 每個數字磚（在職委員 113／提案 7,402／已三讀 656／預算審議中 2,831）都可點進對應頁面。

### 3.3 委員查詢：讓名錄當主角
- 席次圖單獨一區（原本與委員會組成圖並排，兩個圖互搶注意力）。
- 「委員會組成 + 最近異動」收進預設收合的 `<details>`。

### 3.4 型級與層級（全站）
- 建立 9 級 type scale token（`--fs-2xs` … `--fs-3xl`），把 15 種散落字級全部收斂（17→16、19→18、23/24→22）。
- 議案／基金／預算／委員會共用的清單列重新分層：**標題 15px 深墨、最多兩行**；中繼資料 12px 灰字；
  列與列之間用留白取代框線。
- 篩選膠囊：未選取＝無框灰字，選取才上 accent 底（原本一排 10 幾顆都有框有底，像標籤牆）。

### 3.5 順手修掉的後端問題：429 被當成「不可重試」
同步時 `budget` 與 `records` 兩個階段整批失敗（`HTTP 429`）。
原因：`fetch-ly.mjs` 把**所有 4xx 都視為不可重試**。429 是「請你慢一點」，不是拒絕服務。
- 429／408／425／5xx 改為可重試，並尊重 `Retry-After`；429 多給幾次機會。
- 新增同 host 最小間隔（`LY_MIN_INTERVAL_MS`，預設 400ms），對社群維運的 g0v API 客氣一點。
- 修好後重跑：`budget` 11,290 筆、`records` 1,503 筆、`committee_meets` 1,270 筆全部成功（原本 0 筆）。

## 7. 後續：熱門議題強化與「標籤雲」（同日）

### 7.1 結論：不做隨機散佈的文字雲
先量了文字雲的資料基礎：

| 做法 | 高頻結果 |
| --- | --- |
| 新聞標題不分詞（字元 bigram） | 政治(473)、新聞(319)、**沈伯(309)、伯洋(309)**、立委(226)、**蔣萬(211)、萬安(221)** |
| 新聞標題粗略分詞 | 政治(333)、**自由電子(101)**、**民視新聞(74)**、**太報(49)**、沈伯洋(57) |

人名被切斷、媒體名與「政治／新聞」這類無資訊詞佔滿版面；要做得好需要中文分詞＋停用詞＋實體過濾，
做完前幾名還是人名——那正是「排行榜」在做的事。加上面積不可比較、螢幕閱讀器讀不出輕重、
與「顏色只代表黨籍」的規則衝突，因此**改成受控詞彙的標籤檢視**。

### 7.2 熱門議題做了什麼
- **三個區間**：本屆／90 天／30 天／7 天，寫進 URL（`?days=`），與排行榜一致。
- **三種受控詞彙**：法律名稱（632 種）／議案類別（含預算案）／委員會（會議場次），`?vocab=`。
- **每項都多了**：近 7 天件數、前一期件數與增減、三讀件數、最新進度（日期／狀態／議案）、主提案黨籍分布。
- **兩種檢視**：長條（含名次與增減）與標籤，`?view=`。
- **標籤檢視**：三段字級（前 1/3 大、中 1/3 中、其餘小，規則固定不隨機）、件數固定排序、
  每個標籤都有 `title` 提示（件數／近 7 天／增減／三讀／黨籍／最新進度），
  另外提供一份 `.sr-only` 清單給螢幕閱讀器。

### 7.3 誠實面對資料本身
- **議案類別只有 8 種**，且 99% 集中在「法律案」→ 介面直接顯示
  「此詞彙在期間內只有 8 種，清單已全部列出」，不假裝是熱門分布。
- **委員會詞彙的資料只到 2026-08-26**（公報紀錄落後於議案），所以每個詞彙各自 anchor 在自己的最新日期，
  並在說明列標出「資料截至」。
- **增減只在可比時顯示**：本屆累計、或前一期早於資料起點時，`delta` 一律為 0 並在畫面說明，
  不報假的成長率。
